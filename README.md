# 🏝️ Dead City: Island Z
## 게임 디자인 문서 (GDD) v0.1

---

## 📖 게임 개요
- **장르**: 오픈월드 생존 RPG (멀티플레이어)
- **플랫폼**: PC (Unity 2022 LTS)
- **레퍼런스**: 야생의 땅 듀랑고 + Project Zomboid + Last Day On Earth
- **세계관**: 영화 '반도' 기반 — 도시 붕괴 후 생존자들이 섬으로 피신, 자원 부족으로 다시 폐허 도시로 원정

---

## 🗺️ 세계 구조

### 섬 (안전지대 / 베이스캠프)
- 생존자들의 주거 공간
- 건물 건설, 농사, 제작
- PvP 없음 (세이프존)
- 클랜/커뮤니티 기반 운영

### 도시 (위험지대 / 원정지)
- 좀비/적대 NPC 존재
- 고가치 자원, 장비, 설계도 수집
- PvP 가능
- 구역별 위험도 차등 (녹색→노란색→빨간색→블랙존)

---

## 🎮 핵심 게임플레이 루프

```
섬 귀환 → 자원 정리/제작 → 원정 준비 → 도시 탐색 → 전투/채집 → 귀환
```

---

## 📊 캐릭터 스탯 시스템 (듀랑고 참고)

### 생존 스탯
- ❤️ 체력 (HP)
- 🍗 배고픔 (Hunger) — 시간당 감소
- 💧 갈증 (Thirst) — 시간당 감소
- 😴 피로도 (Stamina) — 행동 시 감소
- 🌡️ 체온 (Temperature) — 환경에 따라 변동
- 🩸 출혈 (Bleed) — 전투 디버프

### 스킬 시스템 (듀랑고 스타일)
- 채집, 제작, 건설, 전투, 요리, 농업 등 행동 기반 숙련도 성장

---

## 🎒 인벤토리 시스템 (Project Zomboid 참고)

- 그리드 기반 인벤토리 (무게 제한)
- 장비 슬롯: 머리, 상의, 하의, 신발, 손, 백팩
- 컨테이너 상호작용 (상자, 차량 트렁크 등)
- 아이템 내구도 시스템
- 빠른 슬롯 (핫바) 8칸

---

## ⚔️ 전투 시스템 (Last Day On Earth 참고)

- 탑다운 시점 실시간 전투
- 근접/원거리 무기
- 스태미나 소모 기반 공격
- 회피 (구르기)
- 적: 일반 좀비, 특수 좀비, 적대 생존자 (NPC/Player)

---

## 🏗️ 건설 시스템 (듀랑고 참고)

- 그리드 기반 건설 (섬 내)
- 기초 → 벽 → 바닥 → 지붕 → 가구
- 건물 업그레이드 (나무→돌→금속)
- 트랩 설치 가능

---

## 🔨 제작 시스템

- 레시피 기반 제작
- 워크테이블 종류별 제작 가능 아이템 다름
- 설계도 획득으로 레시피 잠금 해제

---

## 🗺️ 맵 구조

### 월드맵
- 섬 (허브) — 항상 접근 가능
- 도시 구역 (A~F) — 위험도별 분류
- 특수 지역: 군사기지, 병원, 쇼핑몰, 지하 벙커

### 미니맵
- 탐색된 지역만 표시
- 적 위치 표시 (스킬 조건)
- 마킹 기능

---

## 👥 멀티플레이 & 소셜

- 클랜 시스템
- 클랜 영토 (섬 내 구역)
- 교역 시스템
- 파티 원정 (4인 최대)

## 📁 Unity 프로젝트 구조

```
Assets/
├── Scripts/
│   ├── Player/          # 플레이어 컨트롤, 스탯
│   ├── World/           # 월드 생성, 청크
│   ├── Inventory/       # 인벤토리 시스템
│   ├── UI/              # 모든 UI 스크립트
│   ├── Combat/          # 전투 시스템
│   ├── Survival/        # 생존 스탯 (배고픔 등)
│   ├── Crafting/        # 제작 시스템
│   ├── Building/        # 건설 시스템
│   ├── Map/             # 맵 & 미니맵
│   ├── Network/         # 멀티플레이
│   ├── Manager/         # 게임 매니저들
│   └── Data/            # ScriptableObject 데이터
├── ScriptableObjects/   # 아이템, 레시피, 스킬 데이터
├── Prefabs/             # 프리팹
└── Resources/           # 동적 로드 리소스
```
